# 青坊食品行 帳單處理工具

青坊食品行內部使用的帳單整理工具，讓團隊成員能在瀏覽器中快速處理 Excel 帳單，所有運算皆在本機完成，不需上傳任何資料至伺服器。

## 主要功能

- **帳單格式化**：上傳原始 Excel 帳單，自動整理成標準格式後下載
- **客戶資料管理**：自動彙整客戶訂單與消費記錄
- **數據分析**：視覺化呈現銷售趨勢、新舊客戶流量與跨月數據比較
- **順豐託運單**：填寫收件人資訊並匯出順豐格式的託運單，支援常用地址收藏
- **設定匯出／匯入**：所有偏好設定可匯出備份或分享給其他成員

## 使用方式

直接在瀏覽器開啟工具網址，上傳 Excel 檔案後即可使用，無需安裝任何軟體。
